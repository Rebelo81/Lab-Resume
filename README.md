## 📘 Sobre o Projeto

Este repositório apresenta um projeto prático de **provisionamento de máquinas virtuais (VMs)** utilizando a plataforma **Microsoft Azure**, como parte do desafio do bootcamp promovido pela **DIO em parceria com a XP Inc**. O objetivo é entender na prática os fundamentos da computação em nuvem e aplicar os primeiros comandos no ambiente da Azure para gerenciar recursos de forma eficiente.

---

## 🎯 Objetivo

- Criar e configurar uma máquina virtual no Azure usando a **Azure CLI**.
- Compreender os principais conceitos de **Infraestrutura como Serviço (IaaS)**.
- Realizar o primeiro provisionamento de recursos na nuvem com foco em ambiente de desenvolvimento.

---

## 🛠️ Tecnologias Utilizadas

- Microsoft Azure  
- Azure CLI  
- SSH  
- Ubuntu LTS (imagem da VM)
